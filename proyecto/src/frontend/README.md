# Frontend - HTML, CSS, JavaScript

Place your frontend files here. This directory is mapped to the web server's public directory.

## Structure

```
frontend/
├── index.html          # Main entry point
├── css/
│   └── style.css       # Styles
└── js/
    └── app.js          # JavaScript
```

## Accessing from Browser

Files placed here are accessible at `http://localhost:8000/`
